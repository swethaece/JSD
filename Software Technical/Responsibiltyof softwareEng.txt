Responsibility for entry level Software Engineer:
-------------------------------------------------
       *Developing solution
       *Testing and fialising solution
       *Fixing errors
       *Coordinating and communicating with a team and other stackholders
       *Learning and teaching new technologies and skills

1)Developing solutions:
-----------------------
       *understand the task that is beingasked you
       *Review existing documentation on the topic (online or inside the company)
       *propose an approach to save the task.
       *ask questions as needed to clarify task.
       *use coding best practice and design pattern.(ex:naming conversion,track changes,versioncontrol,
       consistency throughout code,make code self explanatory)
       *write code needed for solution
       *reuse code when appropriate

2)Tesing and Finalising solution:
---------------------------------
       *use DevOps approach to makee code reviews along the coding process.
       *have knowledge of be willing to self-tech about test (eg:unit testing)
       *track code production(eg:APM to track system and discover error)
       *test solutions across different Software

3)Fixing error:
---------------
       *locate the code that contains error independently or with support from colleagues
       *test the functionality that has an error
       *understands the technical detail of the current error.
       *test the solution is working correctly
       *test everything that can be affected by the error.

4)Coordinating and communicating with a team and other Stackholders:
--------------------------------------------------------------------
       *participate  in and organise team discussions (eg:Sprint planning, daily scrum, sprint retospective)
       *use team meetings as an opportunity to raise questions and problems.(concerning your own/others work)
       *define situations in which it acceptable to reach out to a colleague for help vs independent
        problem solving.
       *find trusted contact persons who are willing to help
       *identify desired ways of support provided by selected contact persons.(pair programming, online
       chat tools like stack,reviews on Github,etc..)

5)Learning and teaching new technologies and skills:
----------------------------------------------------
       *have knowledge of be willing to self-teach about programming language(object oriented &
       functional development) nd my other needed tool.
