OOPS:(very important)
=====================

    Oops:Object Oriented Programing Structure

    Object:instance of the class

    class:class is user defined data type.
          *class is a blue print.
          *class is a template.
          *class is a common strucyure and behavior to all subjects.
          *class is a hierarchy.

Syntax: class
        class classname
        {
            variables
            methods()
        }

Syntax: Object
        classname objectname =new classname(parameters or args);

Syntax: how to access class members(variables+methods)

        objectname.variablename;
        objectname.methodname();

        note: here (.) is membership operator.
